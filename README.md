
# AgendaVet

Projeto acadêmico de Engenharia de Software II.

O objetivo é refatorar um sistema de agendamento de uma clínica veterinária, aplicando princípios SOLID, Clean Code e padrões de projeto.

## Tecnologias
- TypeScript
- Node.js
- Git e GitHub

## Como executar

Instale as dependências:

```bash
npm install
```

Execute o projeto:

```bash
npm run dev
```
