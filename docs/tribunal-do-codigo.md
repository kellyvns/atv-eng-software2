# Tribunal do Código — AgendaVet

Análise do código legado `src/legado/sistema.ts` (classe `GerenciadorClinica`).

| Trecho / linha                            | Problema (smell)                                                 | Princípio violado                | Como corrigimos                                                                                                      |
| ----------------------------------------- | ---------------------------------------------------------------- | -------------------------------- | -------------------------------------------------------------------------------------------------------------------- |
| `fazer(d: any)`                           | Nome não revela intenção; `any` esconde o contrato               | Clean Code — nomes               | `agendar(dados: NovaConsulta)` na `ClinicaFacade`                                                                    |
| `lista: any[]`                            | Coleção sem tipo; qualquer coisa pode ser guardada               | Clean Code — tipagem             | Interface `Consulta` e `Map<number, Consulta>` no `RepositorioEmMemoria`                                             |
| `if (d.t == 1) ... else if (d.t == 3)`    | Novo serviço exige editar a classe                               | OCP                              | Interface `RegraDePreco` + `PrecoConsulta`, `PrecoVacina`, `PrecoCirurgia`, `PrecoBanhoTosa`                         |
| `1, 2, 3`, `120 * 4.5`, `0.2`             | Números mágicos                                                  | Clean Code                       | Enum `TipoAtendimento` e constantes nomeadas (`PRECO_CIRURGIA`, `FATOR_DESCONTO_PLANO_PET`)                          |
| `if (d.plano == true) v = v - v * 0.2`    | Desconto embutido com `if` no meio do cálculo                    | OCP                              | Decorator `DescontoPlanoPet`, que embrulha a regra original                                                          |
| `status: 'AG'` / `'CN'`                   | Status em siglas obscuras                                        | Clean Code — nomes               | `type StatusConsulta = 'AGENDADA' \| 'CANCELADA'`                                                                    |
| Classe `GerenciadorClinica` inteira       | Valida + calcula + guarda + notifica (classe "Deus")             | SRP                              | Responsabilidades separadas em `CalculadoraDePreco`, `RepositorioEmMemoria`, `ZapAdapter` e `ClinicaFacade`          |
| `zap = new ZapLegacySDK('TOKEN-123')`     | Dependência concreta criada com `new` dentro da classe           | DIP                              | Facade recebe `IRepositorioConsultas`, `CalculadoraDePreco` e `INotificador` pelo construtor; montagem no `index.ts` |
| `this.zap.dispararMsg('55' + d.tel, ...)` | Regra de negócio acoplada à API da biblioteca e ao DDI           | DIP / ISP                        | `ZapAdapter implements INotificador` acrescenta o DDI 55 e traduz a chamada                                          |
| `console.log('erro'); return null;`       | `console.log` como tratamento de erro; retorno `null` silencioso | Clean Code — tratamento de erros | Validação na Facade lança `Error` com mensagem clara                                                                 |
| `id: this.lista.length + 1`               | Id gerado pelo tamanho da lista (pode repetir)                   | SRP / Clean Code                 | Repositório gera o id com contador próprio                                                                           |
| `for (let i = 0; ...)` em `cancelar`      | Busca manual; cancela duas vezes sem avisar; retorna `boolean`   | Clean Code                       | `buscarPorId` + `atualizar`; `cancelar` lança erro se não existir ou já estiver cancelada                            |
